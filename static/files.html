Files

Upload a file, get a link.


Usage

Upload a file
curl -X POST {origin}/files \
  -F "file=@photo.jpg"
Download a file
curl {origin}/files/<id>/raw -o photo.jpg
Download with rate limit (KB/s)
curl "{origin}/files/<id>/raw?rate=100" -o photo.jpg
Download over a specific duration (seconds)
curl "{origin}/files/<id>/raw?duration=30" -o photo.jpg
